# Architectural Decision Records (ADRs)

This directory tracks significant architectural decisions for this project.

## Numbering and Naming Convention
* Format: `XXXX-short-descriptive-title.md` (e.g. `0001-record-architecture-decisions.md`).
* Sequential 4-digit numbering starting at `0001`.
* Copy [`template.md`](./template.md) to initialize a new record.

## Lifecycle
1. **Proposed**: Under review and debate.
2. **Accepted**: Approved and actively implemented.
3. **Superseded**: Replaced by a newer ADR (must link to the succeeding ADR).
4. **Deprecated**: No longer applicable.
