# Workflows — переиспользуемые GitHub Actions

Публичный каталог **переиспользуемых workflows GitHub Actions** для всех
репозиториев `Danyanadamu`. Все потребители закрепляются на один и тот же
подписанный тег:

```yaml
jobs:
  ots:
    uses: Danyanadamu/Workflows/.github/workflows/ots.yml@v1
```

## Зачем отдельный публичный репозиторий

GitHub — **единственный origin** для всех репозиториев организации; серверы
(`Glacier`, `Berg`, `Floe`) держат только push-only зеркала в формате bare-репозиториев и никакой веб-оболочки. Переиспользуемые workflows можно
подключать только из публичного репозитория (или из своего же), поэтому этот
каталог публичен **по дизайну** и, следовательно, не содержит **ни одного
секрета**: все ключи, токены и учётные данные живут в секретах вызывающего
репозитория и попадают сюда через `secrets: inherit`.

## Каталог

| Workflow | Назначение |
| --- | --- |
| [`mirror.yml`](.github/workflows/mirror.yml) | Зеркалирует все refs вызывающего репозитория в bare-репозиторий git-сервера по выделенному push-only SSH-ключу |
| [`ots.yml`](.github/workflows/ots.yml) | Ежедневное обновление и полная проверка доказательств OpenTimestamps + перекрёстная сверка заголовков блоков по двум независимым RPC-провайдерам, с отправкой доказательств обратно в `main` вызывающего репозитория |
| [`deploy.yml`](.github/workflows/deploy.yml) | Деплой rootless-quadlet с закреплением по digest, захватом предыдущего известного-хорошего digest, fail-closed самопроверкой и обязательным откатом |

## Подключение

1. Заведите нужные секреты/переменные **в вызывающем репозитории**, не здесь:
   - `mirror.yml`: `MIRROR_KEY`, `MIRROR_HOST_KEY` (на каждый целевой сервер)
   - `ots.yml`: `BTC_GETBLOCK_KEY`
   - `deploy.yml`: `DEPLOY_KEY`, `DEPLOY_HOST_KEY`
2. Добавьте caller-workflow в `.github/workflows/` своего репозитория с
   `uses: Danyanadamu/Workflows/.github/workflows/<имя>.yml@v1`
   и `secrets: inherit`.
3. Обновляйтесь только через переподписанные теги `v1` — этот каталог никогда
   не публикует «плавающий» контракт `@main`.

## Доверие

Все коммиты и теги подписаны SSH-ключом (`danya-git`) и запечатаны в биткоин
через OpenTimestamps — инструкции по проверке в [`SECURITY.md`](SECURITY.md).
